# Imagens de origem

Este diretório mantém apenas instruções no repositório. Os arquivos originais e capturas de referência usados durante a criação são materiais locais e não são publicados.

Para executar npm run optimize:images, obtenha autorização para as imagens e coloque nesta pasta os arquivos de origem com os nomes esperados pelo script scripts/optimize-images.mjs. Não adicione imagens de clientes, marcas de terceiros, pessoas identificáveis ou documentos sem autorização adequada.
